# Crosshair

Прозрачный оверлей-прицел (крестик) поверх всех окон на **PySide6**. Маленькое
окно висит по центру основного монитора, не перехватывает клики и не занимает
место в панели задач — удобно как «мушка» в играх и приложениях без своего
прицела.

## Возможности

- окно без рамки и заголовка, всегда поверх остальных окон (`WindowStaysOnTopHint`);
- клик-сквозь (`WindowTransparentForInput`) — мышь и клавиатура работают с окном под прицелом;
- прозрачный фон (`WA_TranslucentBackground`) и показ без активации (`WA_ShowWithoutActivating`);
- автоматическое позиционирование в центре основного монитора;
- настраиваемые размер, толщина штрихов, зазор в центре и цвет;
- сглаживание линий (`Antialiasing`) и скруглённые концы штрихов (`RoundCap`).

## Требования

| Компонент | Версия |
| --- | --- |
| Python | 3.11+ (в проекте — 3.12) |
| PySide6 | 6.8+ (проверено на 6.12) |
| Poetry | опционально, для установки из `pyproject.toml` |

## Установка и запуск

```bash
git clone https://github.com/hvdxxx/crosshair.git
cd crosshair

python -m venv .venv
# Windows (PowerShell)
.venv\Scripts\Activate.ps1
# Linux / macOS
source .venv/bin/activate

pip install PySide6
```

Код пакета лежит во вложенном проекте `crosshair/src`, поэтому запуск — из этой
папки (иначе Python примет за пакет сам каталог репозитория):

```bash
# из корня репозитория
cd crosshair/src
python -m crosshair.main
```

Альтернатива — Poetry из вложенного проекта:

```bash
cd crosshair        # вложенный проект с pyproject.toml и src/
poetry install
poetry add PySide6  # зависимости в манифесте не объявлены
poetry run crosshair
```

> Прицел клик-сквозной и не показывается в панели задач, поэтому закрывается
> завершением процесса: `Ctrl+C` в консоли, где он запущен, или через диспетчер
> задач.

## Настройка

Все параметры — аргументы конструктора `CrosshairOverlay` и задаются в
`crosshair/src/crosshair/main.py`:

| Параметр | По умолчанию в классе | Передано в `main.py` | Смысл |
| --- | --- | --- | --- |
| `size` | 48 | 32 | размер окна прицела, px |
| `thickness` | 100 | 2 | толщина штрихов, px |
| `gap` | 8 | 4 | зазор в центре, px |
| `color` | `QColor(0, 255, 0, 220)` | не задан | цвет, включая альфу |

Пример своего прицела:

```python
from PySide6.QtGui import QColor

overlay = CrosshairOverlay(
    size=40,                     # окно 40×40
    thickness=3,                 # штрихи 3 px
    gap=5,                       # зазор 5 px
    color=QColor(255, 60, 60, 230),  # красный, полупрозрачный
)
overlay.show()
```

## Как это работает

1. `QWidget` получает флаги `FramelessWindowHint | WindowStaysOnTopHint | Tool |
   WindowTransparentForInput` — окно без рамки, поверх всех, без записи в панели
   задач и не принимает ввод.
2. `WA_TranslucentBackground` делает фон прозрачным.
3. `_center_on_screen()` берёт `primaryScreen().geometry().center()` и смещает
   окно так, чтобы геометрический центр прицела совпал с центром экрана.
4. `paintEvent()` рисует четыре отрезка (`QPainter.drawLine`) вокруг центра:
   два вертикальных и два горизонтальных, оставляя зазор `gap`.

## Известные ограничения

- `overley.py` содержит отладочный `print(center)` — печатает координаты центра экрана при старте.
- Прицел всегда на основном мониторе; выбора экрана и произвольной позиции нет.
- Из-за `- 1` в `_center_on_screen()` центр прицела смещён примерно на 1 px вправо-вниз от геометрического центра экрана.
- Если запускать с `PYTHONPATH` из корня репозитория, `import crosshair` подхватит каталог репозитория как namespace-пакет и упадёт с `ModuleNotFoundError: No module named 'crosshair.main'`. Надёжнее запускать из `crosshair/src`.
- Значения по умолчанию в классе (`size=48`, `thickness=100`) несовместимы между
  собой: штрих толще окна. Рабочая комбинация передаётся в `main.py` (32/2).
- Настройки меняются только правкой кода — нет CLI-аргументов, горячих клавиш,
  меню и сохранения пресетов.
- В репозитории два независимых Poetry-проекта: корневой ничего не ставит
  (`package-mode = false`), а во вложенном `[project].dependencies` пуст, хотя код
  импортирует `PySide6`. Поэтому `poetry install` из корня не создаст рабочее
  окружение — нужен `pip install PySide6`.
- `tests/` пуст — автотестов нет.
- Нет `LICENSE`.
- `.idea/` закоммичена в репозиторий.

## Дисклеймер

Оверлеи-прицелы в онлайн-играх могут нарушать пользовательское соглашение и
правила античита; возможна блокировка аккаунта. Проект предоставляется «как есть»,
ответственность за использование — на пользователе.
